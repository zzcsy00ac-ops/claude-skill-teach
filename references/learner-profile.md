# Learner Profile (学习者档案)

> 解决"单会话局限"——当前 plan file 是孤立的，没有跨 topic 的长期学习轨迹。
> 基于 KST "准备学习"概念（Doignon & Falmagne 1999）、开放学习者模型 OLM（Bull 2020）、
> 三层记忆架构（设计假设，未经独立验证）。

## 档案文件

**位置（查找顺序）：**
1. `~/.teach/learner-profile.md`（全局固定，首选）
2. `./.teach-learner-profile.md`（cwd 兜底，兼容旧版）

首次创建时写入路径 ①。若路径 ② 已存在（旧版数据），读取后迁移到路径 ① 并告知用户。

**目录创建：** 首次使用时自动 `mkdir -p ~/.teach/`。

**创建时机：** 第一次 `/teach` 时创建。之后每次 `/teach`（无参数或有参数）都先读取。

## 档案格式

```markdown
# 学习者档案
- 创建：<date> · 最近更新：<date>
- 学习风格：<快节奏实操型 / 深度理解型>
- 长期目标：<如 "转Go后端" / "考中级工程师">

## 学习旅程（时间倒序）
| 日期 | Topic | 阶段进展 | 掌握度 | 观察 |
|------|-------|----------|--------|------|
| 2026-08-07 | Go并发 | 3/4 完成 | Relational | goroutine/channel 掌握好，context 概念模糊 |

## 知识状态索引（概念 → 掌握度）
| 概念 | tier | streak | SOLO层级 | 上次练习 | 前置依赖 | 复习到期 |
|------|------|--------|---------|----------|----------|----------|
| goroutine | 掌握 | 3.5 | Relational | 2026-08-07 | — | 2026-08-15 |
| channel | 巩固 | 6 | Relational | 2026-08-07 | goroutine | 2026-08-15 |
| context | 未掌握 | 1 | Unistructural | 2026-08-07 | goroutine | 2026-08-09 |

> **tier/streak** (v3): 三档离散化掌握度。详见 `references/mastery-scoring.md`。
> 独立答对 streak +1 · Recovery L1-2 辅助 +0.5 · 答错归零+降档
> Coverage Gate 通过条件: tier ≥ 掌握。compress 模式例外见 SKILL.md。

## 跨 Topic 关联
- Go并发 → [依赖] Go基础语法
- Go并发 → [前置] 分布式系统基础
```

### 字段说明

- **掌握度**：用 SOLO 层级标注——Prestructural / Unistructural / Multistructural / Relational / Extended Abstract
- **状态**：未学 / 学习中 / 模糊 / 掌握 / 遗忘
- **复习到期**：按 1→2→4→8→16 天间隔计算，到期后状态标记为"需复习"
- **前置依赖**：该概念依赖的其他概念（KST 前置关系）

## 随时继续机制

### `/teach`（无参数）

读取学习者档案，展示学习旅程：

> "你的学习旅程：
> - **Go并发** — 3/4 完成（上次 8/7）
> - **SQL 基础** — 全部完成 ✅（上次 7/30）
>
> 继续学 Go并发 的下一个阶段？还是想学新内容？"

### `/teach <新topic>`

1. **前置知识检查**（KST "准备学习"）：新 topic 是否有前置依赖已在档案中？
   - 前置全部掌握 → 直接开始
   - 前置部分缺失/模糊 → 先桥接："学这个之前，你还需要知道 X——我们先花 5 分钟过一下？"
   - 前置完全未学 → 建议先学前置："这个主题需要先有 Y 基础，建议先学 Y。"

2. **跨 topic 遗忘检查**（RIF 防范）：
   - 档案中复习到期项 ≥3 → 提醒："你有几个之前学过的概念到期复习了，要不要先花 5 分钟快速回顾？"
   - 到期项 <3 → 跳过，直接开始

3. 检查完成后，正常进入 Frame → Diagnose → Plan 流程

## 档案更新时机

| 事件 | 更新内容 |
|------|----------|
| 阶段通过 Feynman | 知识状态索引：对应概念更新掌握度 + 练习日期 |
| 会话结束 | 学习旅程表：添加/更新行 + 进度 |
| Performance Task 通过 | 概念掌握度升级（通常 → Extended Abstract） |
| API 错误修正 | 观察：记录修正内容 |
| 诊断完成 | 如果发现已掌握的前置概念，记录到知识状态索引 |

## 与 Plan File 的关系

- **Plan file** = 单次学习计划（topic 级别，临时）— 位于 `~/.teach/{topic}-plan.md`
- **Learner Profile** = 跨 topic 持久层（学习者级别，长期）— 位于 `~/.teach/learner-profile.md`
- Plan file 的进度日志在会话结束时**同步**到 Learner Profile 的学习旅程表
- Learner Profile 不替代 plan file——它是 plan file 之上的一层

## RIF 防范（检索诱导遗忘）

学习新内容可能加速旧内容遗忘（RIF 效应，Anderson 2003）。通过以下机制缓解：

1. **跨 topic 遗忘检查**：新 topic 开始前检查到期复习项
2. **关联提醒**：教学新概念时，如果它与已学概念有关联，主动提及："还记得你之前学的 X 吗？这个新概念和它的关系是……"
3. **螺旋回归**：在后期阶段主动回溯早期概念（详见 depth-framework.md 螺旋回归）

## 轻量级原则

Learner Profile 是**辅助层**，不是教学的核心负担：
- 更新档案每会话最多花 30 秒——不要让档案管理喧宾夺主
- 如果档案不存在（第一次使用），不阻塞教学流程——创建后继续
- 档案信息用于增强教学个性化，不是强制流程
